Collector design

TopicBehavior
Sources (sim today)Arista eAPI / CloudVision + NVIDIA UFM counters (normalized in sim)
CadenceOnce per calendar minute (NET_SAMPLE_INTERVAL_SEC=60), independent of 2s facility ticks
Hot path…:net:latest JSON snapshot → Uplink / Top Talkers rank without scanning history
1h rings…:net:hist:{device}/{iface} list · RPUSH + LTRIM 60 · fields in/out/u/e/d
Tracked portsDCIM focus set per switch (uplinks, sample access, peers, mgmt) — not every physical ASIC port
Metricsin_bps · out_bps · util_pct · errors · discards · oper · speed_bps
Why RedisSub-ms Top Talkers for operators; long-term archive can later spill to TSDB while Redis stays the 1h cache
